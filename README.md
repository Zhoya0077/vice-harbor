# Vice Harbor

Vice Harbor is an open-world city crime game built for the make.fun Make GTA 6 bounty. One five-minute shift in a neon coastal city you can roam on foot or by car: take phone jobs across four districts, run deliveries, checkpoint circuits and cash grabs for pay, and build a wanted level until the police are on you — then shake them by breaking line of sight, swapping cars while unseen, or outdriving them. It is one static page with no build step: `game/index.html` loads `game/src/main.js` as a plain ES module, no libraries, no bundler, no network requests, and it plays offline straight from the folder.
